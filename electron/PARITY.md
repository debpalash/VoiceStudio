# Electron parity ledger

Goal: all user-visible Tauri capabilities in the Electron app, using existing
backend/domain code and the established T3-inspired shadcn/Base UI shell.
A route or a screenshot alone does not count as parity.

## Design contract

- Keep the expanding script editor, bottom generation controls and independent player.
- Use integrated, resizable panes for contextual work. Reserve dialogs for destructive confirmation.
- Keep each workspace's local controls in the shared readable secondary-sidebar hierarchy; it resizes on desktop, reflows above content when narrow and preserves a labelled rail when collapsed.
- Use existing brand assets, semantic theme tokens, local typography and Lucide icons.
- Simple primary flows; advanced controls remain available through progressive disclosure.
- Reuse domain/API behavior, not legacy Tauri CSS or embedded legacy pages.
- Preserve local-first behavior, existing user data and cross-platform capabilities.
- Every new visible string is translated into all 21 locales.
