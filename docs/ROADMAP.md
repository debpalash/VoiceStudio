# VoiceStudio roadmap

The live roadmap is [issue #3425](https://github.com/debpalash/VoiceStudio/issues/3425).
Use the [open issues](https://github.com/debpalash/VoiceStudio/issues) and
[open pull requests](https://github.com/debpalash/VoiceStudio/pulls) for current
scope, decisions, dependencies and implementation status.

For what the app supports today, see the [feature catalog](feature-catalog.md),
[Electron parity tracker](../electron/PARITY.md) and [mobile guide](mobile.md).
[Design references](specs/README.md) provide context for specific proposals;
they do not replace current implementation or issue status.

The former phase-by-phase roadmap described the retired frontend and Tauri
shell. Its estimates, progress percentages and implementation paths are
available in git history and are no longer maintained as a parallel backlog.
