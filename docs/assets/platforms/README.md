# Platform icons

Flat rose glyphs for the README platform table. The shared `#b46787` fill stays visible on GitHub’s light and dark backgrounds. Images are decorative beside the existing platform names.

Apple, Linux, Docker and Android paths are from [Simple Icons](https://github.com/simple-icons/simple-icons/tree/90646e4bf7f3b89df6c37e65baf3e7bc759a517c/icons), commit `90646e4bf7f3b89df6c37e65baf3e7bc759a517c`, under [CC0-1.0](LICENSE-CC0.md). Only the SVG wrapper and fill have changed. Brand marks belong to their respective owners.

The Windows four-pane glyph is repository-authored and follows the repository license.
