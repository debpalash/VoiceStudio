# Commercial License client: verify, check status, test

**Status:** Candidate protocol; provider selection and production implementation pending

**Date:** 2026-09-29

**Scope:** Public client-side verification and refresh contract for the candidate vssaas licensing integration. This document does not select the payment/licensing provider or claim that the maintained client implements this protocol.

Private service implementation paths, operator procedures, database layouts and local service setup belong in the private service documentation. They are intentionally absent from this public client contract. Removing them here does not remove earlier Git history.

Public protocol vocabulary:

- **Commercial License**: the grant.
- **License Seat**: one counted Installation.
- **License Key**: `VSLK-…`, shown to the licensee once.
- **Installation Credential**: `vsic_…`, generated by the client.
- **License Certificate**: `vslc1.…`, short-lived and verifiable offline.

## 1. Verify a License Certificate

### 1.1 Algorithm

The verification order is part of the proposed wire contract; conformance vectors expect a specific error for each case. `now` is whole Unix seconds.

**Envelope rules.** These apply to both the certificate and the endorsement.

1. The envelope is at most **8192 bytes**. Count UTF-8 bytes, not characters.
2. It starts with the prefix: `vslc1.` for a certificate, `vsle1.` for an endorsement. The rest is exactly `<payload>.<signature>`, with no third segment.
3. Both segments are **strict base64url without padding**: only `A–Z a–z 0–9 - _`, no `=`, no CR or LF, length mod 4 ≠ 1, and canonical trailing bits (decoding and re-encoding gives back the same string). The payload is non-empty, and the signature is 64 bytes.
4. The payload is **one JSON object with exactly the documented keys**. Each key appears once and none is `null`. Integers have no fraction or exponent. There is no BOM and nothing after the object except whitespace. An unknown, missing or duplicate key is an error.

Any failure of steps 1 to 4 is `malformed`.

**Endorsement** (`vsle1.`). Its keys are `v kid public_key env nbf exp root_kid`. It is verified against the embedded roots:

1. Look up the root by `root_kid`. If it is missing, `unknown_key`.
2. Verify the Ed25519 signature over `"vssaas-license-signing-key-v1\x00" || payload_bytes`, using the exact decoded bytes with no re-encoding. If it fails, `bad_signature`.
3. `env` must equal the client's environment. Otherwise `wrong_environment`.
4. `v == 1`; `public_key` is base64url of 32 bytes; `kid == hex(SHA-256(public_key))[0:16]`; `root_kid` is 16 lowercase hex characters; `0 < nbf < exp`. Otherwise `invalid_claims`.
5. If `now < nbf`, `not_yet_valid`. If `now ≥ exp`, `expired`.

Each endorsement that passes adds `kid → public_key` to the trusted key set. A root is never in that set.

**Certificate** (`vslc1.`). Its keys are `v kid iss aud env serial license_id seat_id organization_id inst edition agreement_version term_ends_at updates_until iat nbf exp hard_exp refresh_after`. The integer keys are `v`, `term_ends_at`, `updates_until`, `iat`, `nbf`, `exp`, `hard_exp` and `refresh_after`.

1. Look up `kid` in the trusted key set. If it is missing, `unknown_key`.
2. Verify the Ed25519 signature over `"vssaas-license-certificate-v1\x00" || payload_bytes`. If it fails, `bad_signature`.
3. `aud` must be `"voicestudio-desktop"`. Otherwise `wrong_audience`.
4. `env` must equal the client's environment. Otherwise `wrong_environment`.
5. These must all hold, or `invalid_claims`:
   - `v == 1`, `iss == "vssaas"`, and `env` is one of `development|staging|production`.
   - `kid` is 16 lowercase hex characters.
   - `serial`, `license_id`, `seat_id`, `organization_id`, `edition` and `agreement_version` each match `[A-Za-z0-9._-]{1,64}`.
   - `inst` is base64url of 32 bytes.
   - `iat > 0` and `updates_until > 0`.
   - `0 < nbf ≤ iat`, `exp > iat`, `hard_exp ≥ exp`, `term_ends_at ≥ hard_exp`, and `refresh_after > iat`.
6. **Windows.** If `now < nbf`, `not_yet_valid`. If `now ≥ hard_exp`, `expired`. Otherwise the certificate is valid, and **in grace** when `exp ≤ now < hard_exp`.

Verify the endorsement at the same `now` as the certificate. vssaas never issues a certificate whose `hard_exp` passes its key's endorsement, so a cached endorsement covers the certificate's whole life. The client should also take `now` from a non-decreasing clock: the larger of the system time and the latest time it has already seen, such as the refresh response's `server_time`. Otherwise, setting the clock back extends a certificate.

**Checks the application must add around the verifier.** `verifyCertificate` / `verify_certificate` and the CLI wrappers below prove only that vssaas signed the certificate. They are a reference and a test harness, not the whole gate. The client must also do both of these before it turns Pro on:

- **Bind to this installation.** Compare the verified `inst` claim with this installation's own licensing identifier, the 32 bytes it sent as `installation_id_hash` at claim time (a random licensing-only identifier, independent of analytics and hardware identifiers). On a mismatch, treat the certificate as invalid and do not enable Pro. Without this, a valid certificate copied to another machine would work offline until its `hard_exp` without owning a seat.
- **Persist a time floor.** Store the highest `now` the client has accepted (system time or a refresh response's `server_time`, whichever is larger) and use `max(system time, stored floor)` as `now` on every start. The CLIs take `now` from the command line or the system clock for testing only. Production code that restarts and reads the raw clock would let a rolled-back clock stretch the 44-day offline limit ([§2.4](#24-the-offline-limit)).

### 1.2 Where the root keys come from

Trust starts from one or two **root public keys compiled into the client build**, one set per environment. They are public values, so they can be committed or injected by CI. A good format mirrors vssaas `LICENSE_ROOT_PUBLIC_KEYS`: comma-separated unpadded base64url, 32 bytes each, supplied through a build-time define such as `VOICESTUDIO_LICENSE_ROOT_PUBLIC_KEYS`, next to the existing `VOICESTUDIO_PRO_*` defines in `electron/electron.vite.config.ts`.

- **Production roots.** These come from the offline key ceremony. A production signing-key ceremony is required before production signing; no production roots are established by this draft. A production build contains only production roots.
- **Development and staging roots.** Use dedicated non-production roots supplied through the private service setup process; never trust those roots in production.
- **Never the golden root.** No build trusts the golden-vector root `A6EHv_POEL4dcN0Y50vAmWfk1jCbpQ1fHdyGZBJVMbg`, which is labelled TEST ONLY.
- **Not from the network.** `GET /v1/license-signing-keys` supplies endorsements, not roots. Trust comes only from the compiled roots.
- **Two roots.** Retiring one root needs a client release, and having two means clients stay anchored meanwhile.

### 1.3 TypeScript (Node `crypto`)

Save this as `license-certificate.ts`. It runs as-is with `node --experimental-strip-types` (Node 22.6 or later) or `bun`, and needs no dependencies. `JSON.parse` keeps the last duplicate key and `Buffer.from(…, 'base64url')` is lenient, so the file scans tokens itself.

```ts
// Verifies vssaas License Certificates offline.
import { createHash, createPublicKey, verify, type KeyObject } from 'node:crypto';
import { readFileSync } from 'node:fs';
import { fileURLToPath } from 'node:url';

export type Environment = 'development' | 'staging' | 'production';
export type ErrorCode =
  | 'malformed' | 'unknown_key' | 'bad_signature' | 'wrong_audience'
  | 'wrong_environment' | 'not_yet_valid' | 'expired' | 'invalid_claims';
export class LicenseCertificateError extends Error {
  readonly code: ErrorCode;
  constructor(code: ErrorCode) {
    super(code);
    this.code = code;
  }
}
const fail = (code: ErrorCode): never => {
  throw new LicenseCertificateError(code);
};

type Shape = Record<string, 'str' | 'int'>;
const CLAIMS: Shape = {
  v: 'int', kid: 'str', iss: 'str', aud: 'str', env: 'str', serial: 'str', license_id: 'str',
  seat_id: 'str', organization_id: 'str', inst: 'str', edition: 'str', agreement_version: 'str',
  term_ends_at: 'int', updates_until: 'int', iat: 'int', nbf: 'int', exp: 'int', hard_exp: 'int',
  refresh_after: 'int',
};
const ENDORSEMENT: Shape = {
  v: 'int', kid: 'str', public_key: 'str', env: 'str', nbf: 'int', exp: 'int', root_kid: 'str',
};
const ENVIRONMENTS = ['development', 'staging', 'production'];
const TOKEN = /^[A-Za-z0-9._-]{1,64}$/;
const KID = /^[0-9a-f]{16}$/;

// Strict, unpadded, canonical base64url (Buffer.from alone is lenient).
export function b64url(text: string): Buffer {
  if (!/^[A-Za-z0-9_-]*$/.test(text) || text.length % 4 === 1) fail('malformed');
  const bytes = Buffer.from(text, 'base64url');
  if (bytes.toString('base64url') !== text) fail('malformed');
  return bytes;
}
const is32 = (text: string) => {
  try {
    return b64url(text).length === 32;
  } catch {
    return false;
  }
};
export const keyIdFor = (raw: Uint8Array) => createHash('sha256').update(raw).digest('hex').slice(0, 16);
export const ed25519Key = (raw: Uint8Array): KeyObject =>
  createPublicKey({ key: { kty: 'OKP', crv: 'Ed25519', x: Buffer.from(raw).toString('base64url') }, format: 'jwk' });

// One flat JSON object: exactly the keys in `shape`, each once, never null,
// with the declared type, and nothing but whitespace after it. JSON.parse
// would silently keep the last duplicate key, so scan the tokens.
function exactObject(payload: Buffer, shape: Shape): Record<string, any> {
  const text = new TextDecoder('utf-8', { ignoreBOM: true }).decode(payload);
  const out = new Map<string, string | number>();
  let at = 0;
  const take = (re: RegExp) => {
    re.lastIndex = at;
    const m = re.exec(text);
    if (m) at = re.lastIndex;
    return m ? m[0] : null;
  };
  const ws = () => take(/[ \t\n\r]*/y);
  const str = () => take(/"(?:[^"\\\u0000-\u001f]|\\(?:["\\/bfnrt]|u[0-9A-Fa-f]{4}))*"/y);
  const num = () => take(/-?(?:0|[1-9][0-9]*)(?:\.[0-9]+)?(?:[eE][+-]?[0-9]+)?/y);
  ws();
  if (text[at++] !== '{') fail('malformed');
  ws();
  if (text[at] === '}') at++;
  else
    for (;;) {
      ws();
      const rawKey = str() ?? fail('malformed');
      const key = JSON.parse(rawKey) as string;
      if (!Object.hasOwn(shape, key) || out.has(key)) fail('malformed');
      ws();
      if (text[at++] !== ':') fail('malformed');
      ws();
      if (text[at] === '"') {
        const value = str();
        if (value === null || shape[key] !== 'str') fail('malformed');
        out.set(key, JSON.parse(value!));
      } else {
        const value = num(); // null, true, false, {} and [] all fail here
        if (value === null || shape[key] !== 'int' || !/^-?(?:0|[1-9][0-9]*)$/.test(value)) fail('malformed');
        if (!Number.isSafeInteger(Number(value))) fail('malformed');
        out.set(key, Number(value));
      }
      ws();
      const next = text[at++];
      if (next === '}') break;
      if (next !== ',') fail('malformed');
    }
  ws();
  if (at !== text.length || out.size !== Object.keys(shape).length) fail('malformed');
  return Object.fromEntries(out);
}

function open(envelope: string, prefix: string, domain: string, shape: Shape) {
  if (Buffer.byteLength(envelope, 'utf8') > 8192 || !envelope.startsWith(prefix)) fail('malformed');
  const parts = envelope.slice(prefix.length).split('.');
  if (parts.length !== 2) fail('malformed');
  const payload = b64url(parts[0]);
  const signature = b64url(parts[1]);
  if (payload.length === 0 || signature.length !== 64) fail('malformed');
  const fields = exactObject(payload, shape);
  return { fields, message: Buffer.concat([Buffer.from(domain, 'utf8'), payload]), signature };
}

// roots: root_kid -> root public key. Returns the signing key it vouches for.
export function verifyEndorsement(value: string, roots: Map<string, KeyObject>, env: Environment, now: number) {
  const { fields: e, message, signature } = open(value, 'vsle1.', 'vssaas-license-signing-key-v1\x00', ENDORSEMENT);
  const root = roots.get(e.root_kid) ?? fail('unknown_key');
  if (!verify(null, message, root, signature)) fail('bad_signature');
  if (e.env !== env) fail('wrong_environment');
  if (e.v !== 1 || !ENVIRONMENTS.includes(e.env) || !is32(e.public_key)) fail('invalid_claims');
  const raw = b64url(e.public_key);
  if (e.kid !== keyIdFor(raw) || !KID.test(e.root_kid) || e.nbf <= 0 || e.exp <= e.nbf) fail('invalid_claims');
  if (now < e.nbf) fail('not_yet_valid');
  if (now >= e.exp) fail('expired');
  return { kid: e.kid as string, key: ed25519Key(raw) };
}

// keys: kid -> signing key whose endorsement verified at the same `now`.
export function verifyCertificate(envelope: string, keys: Map<string, KeyObject>, env: Environment, now: number) {
  const { fields: c, message, signature } = open(envelope, 'vslc1.', 'vssaas-license-certificate-v1\x00', CLAIMS);
  const key = keys.get(c.kid) ?? fail('unknown_key');
  if (!verify(null, message, key, signature)) fail('bad_signature');
  if (c.aud !== 'voicestudio-desktop') fail('wrong_audience');
  if (c.env !== env) fail('wrong_environment');
  const valid =
    c.v === 1 && c.iss === 'vssaas' && ENVIRONMENTS.includes(c.env) && KID.test(c.kid) &&
    [c.serial, c.license_id, c.seat_id, c.organization_id, c.edition, c.agreement_version].every((t) => TOKEN.test(t)) &&
    is32(c.inst) && c.iat > 0 && c.updates_until > 0 && c.nbf > 0 && c.nbf <= c.iat && c.exp > c.iat &&
    c.hard_exp >= c.exp && c.term_ends_at >= c.hard_exp && c.refresh_after > c.iat;
  if (!valid) fail('invalid_claims');
  if (now < c.nbf) fail('not_yet_valid');
  if (now >= c.hard_exp) fail('expired');
  return { claims: c, inGrace: now >= c.exp };
}

// Builds the key set from GET /v1/license-signing-keys, trusting only `roots`.
export function trustedKeys(published: { endorsement: string }[], rootKeys: string[], env: Environment, now: number) {
  const roots = new Map(rootKeys.map((r) => [keyIdFor(b64url(r)), ed25519Key(b64url(r))] as const));
  const keys = new Map<string, KeyObject>();
  for (const { endorsement } of published) {
    try {
      const k = verifyEndorsement(endorsement, roots, env, now);
      keys.set(k.kid, k.key);
    } catch {} // an endorsement that does not verify contributes no key
  }
  return keys;
}

// CLI: <certificate or response.json> <signing-keys.json> <root,...> <env> [now]
if (process.argv[1] === fileURLToPath(import.meta.url)) {
  const [certFile, keysFile, roots, env, nowArg] = process.argv.slice(2);
  const raw = readFileSync(certFile, 'utf8').trim();
  const envelope = raw.startsWith('vslc1.') ? raw : JSON.parse(raw).certificate;
  const now = nowArg ? Number(nowArg) : Math.floor(Date.now() / 1000);
  const keys = trustedKeys(JSON.parse(readFileSync(keysFile, 'utf8')).keys, roots.split(','), env as Environment, now);
  try {
    const { claims, inGrace } = verifyCertificate(envelope, keys, env as Environment, now);
    console.log(JSON.stringify({ valid: true, in_grace: inGrace, claims }, null, 2));
  } catch (e) {
    console.log(JSON.stringify({ valid: false, error: (e as LicenseCertificateError).code ?? String(e) }));
    process.exitCode = 1;
  }
}
```

This has one deliberate difference from Go. Integers outside ±(2^53−1) are `malformed`, while Go accepts the full int64 range. Unix-second claims never get there.

### 1.4 Python (`cryptography`)

Save this as `license_certificate.py`. `cryptography` is already a direct VoiceStudio dependency. Outside the project venv, run it with `uv run --no-project --with cryptography python license_certificate.py …`.

```python
"""Verifies vssaas License Certificates offline."""
from __future__ import annotations

import base64
import hashlib
import json
import re
import sys
import time

from cryptography.exceptions import InvalidSignature
from cryptography.hazmat.primitives.asymmetric.ed25519 import Ed25519PublicKey

ENVIRONMENTS = ("development", "staging", "production")
CLAIMS = {"v": int, "kid": str, "iss": str, "aud": str, "env": str, "serial": str, "license_id": str,
          "seat_id": str, "organization_id": str, "inst": str, "edition": str, "agreement_version": str,
          "term_ends_at": int, "updates_until": int, "iat": int, "nbf": int, "exp": int, "hard_exp": int,
          "refresh_after": int}
ENDORSEMENT = {"v": int, "kid": str, "public_key": str, "env": str, "nbf": int, "exp": int, "root_kid": str}
TOKEN = re.compile(r"[A-Za-z0-9._-]{1,64}")  # always fullmatch: "$" would accept a trailing newline
KID = re.compile(r"[0-9a-f]{16}")


class LicenseCertificateError(Exception):
    """code: malformed, unknown_key, bad_signature, wrong_audience,
    wrong_environment, not_yet_valid, expired or invalid_claims."""

    def __init__(self, code: str) -> None:
        super().__init__(code)
        self.code = code


def b64url(text: str) -> bytes:
    """Strict, unpadded, canonical base64url."""
    if not re.fullmatch(r"[A-Za-z0-9_-]*", text) or len(text) % 4 == 1:
        raise LicenseCertificateError("malformed")
    raw = base64.urlsafe_b64decode(text + "=" * (-len(text) % 4))
    if base64.urlsafe_b64encode(raw).rstrip(b"=").decode() != text:
        raise LicenseCertificateError("malformed")
    return raw


def _is32(text: str) -> bool:
    try:
        return len(b64url(text)) == 32
    except LicenseCertificateError:
        return False


def key_id_for(raw: bytes) -> str:
    return hashlib.sha256(raw).hexdigest()[:16]


class _Pairs(list):
    pass


def _reject(_constant):
    raise ValueError("NaN and Infinity are not JSON")


def _exact_object(payload: bytes, shape: dict) -> dict:
    try:  # json.loads rejects a leading BOM and trailing data
        pairs = json.loads(payload.decode("utf-8", "replace"), object_pairs_hook=_Pairs, parse_constant=_reject)
    except (ValueError, RecursionError):
        raise LicenseCertificateError("malformed") from None
    if not isinstance(pairs, _Pairs):
        raise LicenseCertificateError("malformed")
    out = {}
    for key, value in pairs:
        want = shape.get(key)
        # type() excludes bool and null; the int range is Go's int64.
        if want is None or key in out or type(value) is not want or (want is int and not -2**63 <= value < 2**63):
            raise LicenseCertificateError("malformed")
        out[key] = value
    if len(out) != len(shape):
        raise LicenseCertificateError("malformed")
    return out


def _open(envelope: str, prefix: str, domain: bytes, shape: dict):
    if len(envelope.encode("utf-8", "surrogatepass")) > 8192 or not envelope.startswith(prefix):
        raise LicenseCertificateError("malformed")
    parts = envelope[len(prefix):].split(".")
    if len(parts) != 2:
        raise LicenseCertificateError("malformed")
    payload, signature = b64url(parts[0]), b64url(parts[1])
    if not payload or len(signature) != 64:
        raise LicenseCertificateError("malformed")
    return _exact_object(payload, shape), domain + payload, signature


def _signed(key: Ed25519PublicKey, signature: bytes, message: bytes) -> bool:
    try:
        key.verify(signature, message)
        return True
    except InvalidSignature:
        return False


def verify_endorsement(value: str, roots: dict, env: str, now: int) -> tuple[str, Ed25519PublicKey]:
    """roots: root_kid -> root public key. Returns (kid, signing key)."""
    e, message, signature = _open(value, "vsle1.", b"vssaas-license-signing-key-v1\x00", ENDORSEMENT)
    root = roots.get(e["root_kid"])
    if root is None:
        raise LicenseCertificateError("unknown_key")
    if not _signed(root, signature, message):
        raise LicenseCertificateError("bad_signature")
    if e["env"] != env:
        raise LicenseCertificateError("wrong_environment")
    if (e["v"] != 1 or e["env"] not in ENVIRONMENTS or not _is32(e["public_key"])
            or e["kid"] != key_id_for(b64url(e["public_key"])) or not KID.fullmatch(e["root_kid"])
            or e["nbf"] <= 0 or e["exp"] <= e["nbf"]):
        raise LicenseCertificateError("invalid_claims")
    if now < e["nbf"]:
        raise LicenseCertificateError("not_yet_valid")
    if now >= e["exp"]:
        raise LicenseCertificateError("expired")
    return e["kid"], Ed25519PublicKey.from_public_bytes(b64url(e["public_key"]))


def verify_certificate(envelope: str, keys: dict, env: str, now: int) -> tuple[dict, bool]:
    """keys: kid -> signing key whose endorsement verified at the same `now`.
    Returns (claims, in_grace)."""
    c, message, signature = _open(envelope, "vslc1.", b"vssaas-license-certificate-v1\x00", CLAIMS)
    key = keys.get(c["kid"])
    if key is None:
        raise LicenseCertificateError("unknown_key")
    if not _signed(key, signature, message):
        raise LicenseCertificateError("bad_signature")
    if c["aud"] != "voicestudio-desktop":
        raise LicenseCertificateError("wrong_audience")
    if c["env"] != env:
        raise LicenseCertificateError("wrong_environment")
    tokens = ("serial", "license_id", "seat_id", "organization_id", "edition", "agreement_version")
    if not (c["v"] == 1 and c["iss"] == "vssaas" and c["env"] in ENVIRONMENTS and KID.fullmatch(c["kid"])
            and all(TOKEN.fullmatch(c[t]) for t in tokens) and _is32(c["inst"])
            and c["iat"] > 0 and c["updates_until"] > 0 and 0 < c["nbf"] <= c["iat"] and c["exp"] > c["iat"]
            and c["hard_exp"] >= c["exp"] and c["term_ends_at"] >= c["hard_exp"] and c["refresh_after"] > c["iat"]):
        raise LicenseCertificateError("invalid_claims")
    if now < c["nbf"]:
        raise LicenseCertificateError("not_yet_valid")
    if now >= c["hard_exp"]:
        raise LicenseCertificateError("expired")
    return c, now >= c["exp"]


def trusted_keys(published: list, root_keys: list[str], env: str, now: int) -> dict:
    """Key set from GET /v1/license-signing-keys, trusting only root_keys."""
    roots = {key_id_for(b64url(r)): Ed25519PublicKey.from_public_bytes(b64url(r)) for r in root_keys}
    keys = {}
    for item in published:
        try:
            kid, key = verify_endorsement(item["endorsement"], roots, env, now)
            keys[kid] = key
        except LicenseCertificateError:
            pass  # an endorsement that does not verify contributes no key
    return keys


if __name__ == "__main__":  # <certificate or response.json> <signing-keys.json> <root,...> <env> [now]
    cert_file, keys_file, roots_csv, env_name = sys.argv[1:5]
    now = int(sys.argv[5]) if len(sys.argv) > 5 else int(time.time())
    raw = open(cert_file).read().strip()
    envelope = raw if raw.startswith("vslc1.") else json.loads(raw)["certificate"]
    key_set = trusted_keys(json.load(open(keys_file))["keys"], roots_csv.split(","), env_name, now)
    try:
        claims, in_grace = verify_certificate(envelope, key_set, env_name, now)
        print(json.dumps({"valid": True, "in_grace": in_grace, "claims": claims}, indent=2))
    except LicenseCertificateError as exc:
        print(json.dumps({"valid": False, "error": exc.code}))
        sys.exit(1)
```

### 1.5 Golden-vector tests

The examples below require an approved conformance fixture, copied byte for byte to `tests/fixtures/licensing/golden.json`; that fixture is not bundled by this draft. The referenced fixture has SHA-256 `f9008f69434581a3941700680955cac7669c8963a7d88d10d87dba08e23edbec` and contains:

- a TEST ONLY root and signing key;
- one endorsement, verified at its own `now`;
- 3 valid envelopes (`active`, `in_grace`, `clamped_to_term`);
- 8 invalid ones, one per error.

Treat changes to existing conformance vectors as protocol changes. The snippets below are candidate test harnesses, not evidence that the maintained application implements this protocol.

## 2. Check the license is not revoked or suspended

A certificate proves the seat was valid when it was issued. Only a refresh tells the client that the license has since been suspended, revoked or ended, or that the seat was released.

### 2.1 The refresh call

```http
POST /v1/license-seats/{seat_id}/certificates
Authorization: Bearer vsic_<43 base64url characters>
Content-Type: application/json

{ "last_certificate_serial": "<serial of the certificate held now>" }
```

- The bearer is the Installation Credential that the client generated and hashed at claim time. The server compares `SHA-256` of the whole `vsic_…` string in constant time.
- The body is optional. It may be empty or `{}`, and unknown fields are rejected. When a serial is sent, it must be 16 Base62 characters. A serial that differs from the latest one does not by itself reject the refresh.
- There is no `Idempotency-Key`.

A `200` has the same shape as a claim, and carries `Cache-Control: no-store`:

| Field | Value |
| --- | --- |
| `seat.id`, `seat.license_id` | 16-character Base62 IDs |
| `seat.state` | Always `active` on a `200` |
| `seat.claimed_at` | RFC 3339 |
| `license.id`, `license.edition` (`pro`), `license.seat_limit` (1–1000) | License summary |
| `license.state` | The schema allows `active`, `suspended` or `revoked`. It is always `active` on a `200`, because a suspended or revoked license is refused with `403`. |
| `license.ends_at`, `license.updates_until` | RFC 3339 term |
| `certificate` | A `vslc1.…` envelope of at most 8192 bytes. Verify it (§1) before storing it. |
| `certificate_expires_at`, `certificate_hard_expires_at`, `refresh_after` | RFC 3339 copies of the claims `exp`, `hard_exp` and `refresh_after`. Trust the verified claims. |
| `server_time` | The server clock. It is not signed; use it to detect skew and as a floor for the client clock. |

License states:

- The **stored** states are `active`, `suspended` (reversible) and `revoked` (terminal).
- **Expired** (now ≥ `ends_at`) and **not yet active** (now < `starts_at`) are derived from the term, never stored. They appear only as error codes.
- When several conditions hold, the first of these wins: `license_revoked`, `license_suspended`, `license_not_active`, `license_expired`.
- A seat is either `active` or `released`, and a release is never undone. Suspension, revocation and expiry never release seats.

### 2.2 Outcomes and what the client does

Every error uses `{"error": {"code", "message", "request_id", "details"}}`. Map by `code` and keep `request_id` for support.

| Code | HTTP | Meaning | Client action |
| --- | --- | --- | --- |
| — | 200 | Seat and license are good | Verify and store the new certificate, then schedule the next refresh (§2.3) |
| `license_revoked` | 403 | Revoked (terminal) | Turn Pro off now and delete the certificate. Stop refreshing. Offer "use a different License Key". Release still works. |
| `license_suspended` | 403 | Suspended by an operator | Turn Pro off now and delete the certificate. Keep retrying every 6 hours and on the user's "Check now"; a reinstated license refreshes normally. |
| `license_expired` | 403 | now ≥ `ends_at` | Turn Pro off now, delete the certificate, and stop scheduled refreshes. Under this candidate contract, terms are fixed at issuance, so continuing needs a new license and License Key. |
| `license_not_active` | 403 | `starts_at` is in the future | Turn Pro off now and delete the certificate. Seen on claim in practice; retry after the start date. |
| `seat_released` | 409 | The seat was released by this Installation or by an operator, and the credential is correct | Turn Pro off. Delete the seat, certificate and credential. Claiming again needs the License Key. |
| `invalid_installation_credential` | 401 | Unknown seat or wrong credential. The body is identical for both causes. | Keep the current certificate until its `hard_exp`, and stop refreshing. Ask for the License Key to claim again; a `409 installation_conflict` then means an operator must release the old seat. |
| `license_authority_unavailable` | 503 | No usable active signing key, the endorsement is too short, or the signer failed | Keep the certificate and back off |
| `dependency_unavailable` | 503 | Database unavailable | Keep the certificate and back off |
| `rate_limited` | 429 | Over budget | Wait exactly `Retry-After` seconds (at least 1) |
| `invalid_request` | 400 | Malformed body or serial | A client bug. Log the code and `request_id`. |
| any `404` | 404 | The authority has no license configuration, so its routes are not registered | Treat as `license_authority_unavailable` |
| network error or timeout | — | Offline | Keep the certificate and back off |

The rule: a definitive answer (a `403`, or `seat_released`) takes effect immediately — discard the held certificate and disable Pro at once, even while the certificate would still verify. The certificate's own grace until `hard_exp` (§2.4) exists only to cover a claim or refresh that got no definitive answer: vssaas unreachable, a timeout, or a `5xx`, `429` or `license_authority_unavailable` response. A transient failure never shortens a certificate that verifies, and a definitive `403` never waits for one.

### 2.3 When to call

- **Schedule** the next refresh at `min(refresh_after, exp)` from the verified claims. The server sets `refresh_after = iat + 24h + uniform[0, 6h)`, so it already includes jitter. Within 30 days of `ends_at`, `exp` and `hard_exp` both equal `ends_at`: there is no grace, and `refresh_after` can fall after `exp`.
- **Also refresh** at app start when a refresh is due or overdue, after the system wakes, and when the network comes back.
- **Reissue window.** A refresh or replayed claim may return the same certificate and `refresh_after`; the client must accept a valid unchanged certificate without assuming a new one will be issued for every request.
- **429.** Honour `Retry-After`; do not rely on private service rate-limit budgets or retry immediately.
- **503, 404 or network failure.** Back off exponentially from 1 minute, doubling up to 6 hours (up to 1 hour while in grace), with jitter.

### 2.4 The offline limit

An installation learns about a revocation or suspension only when a refresh reaches vssaas. An online installation normally learns within 24 to 30 hours, at its next `refresh_after`. An offline installation keeps a certificate that verifies until that certificate's `hard_exp`. `hard_exp = min(exp + 14 days, ends_at)`, and `exp = min(iat + 30 days, ends_at)`, so this is **at most 44 days after the certificate was issued**. This is the candidate protocol limit, not a published product promise; the selected provider and paid terms must agree before launch. The client cannot shorten it without a network call. The non-decreasing clock in §1.1 stops users from stretching it by rolling the clock back.

### 2.5 Signing-key rotation check

```http
GET /v1/license-signing-keys
```

```json
{ "keys": [ { "kid": "0310b053afb12114", "public_key": "AxCwU6-…", "state": "active", "endorsement": "vsle1.…" } ] }
```

- This route is unauthenticated and cacheable (`Cache-Control: public, max-age=300`). It lists the `active` key and any `retiring` keys.
- Call it when a certificate's `kid` has no cached endorsement that verifies, which happens at the first claim and after vssaas rotates its signing key.
- Verify every `endorsement` against the embedded roots at the same `now` (`trustedKeys` / `trusted_keys` in §1), then verify the certificate again. Never use `public_key` or `state` without its endorsement.
- Never replace a certificate that verifies with one that does not.
- If a successful fetch no longer lists the held certificate's `kid`, refresh at once. The key was retired or compromised, and vssaas answers with a certificate from the active key; its reissue window never returns a certificate signed by a compromised key.
- A retiring key stays published until its last certificate has passed `hard_exp`, so ordinary rotation never strands an offline client.

## 3. Client privacy and production prerequisites

Generate a random identifier solely for licensing; do not derive it from an OS
machine identifier, hostname, username, hardware attributes, analytics identifier
or application encryption key. Keep licence, seat, organisation and installation
values out of analytics. The activation UI and reviewed privacy policy must
explain the selected provider, submitted fields and retention before release.
This draft makes no claim about private service storage or operational logging.

Before enabling this protocol, select the provider, publish approved conformance
fixtures, validate installation binding and persisted clock handling, complete the
production signing-key ceremony, and document the actual offline period. Private
operator runbooks and service internals must remain in the private service's
controlled documentation.
