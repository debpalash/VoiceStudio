## प्लेटफार्म

अपना सिस्टम चुनें, फिर इंस्टॉलेशन विधि का विस्तार करें।

नेटिव GGUF इंजन AMD, Intel और NVIDIA GPU पर इंजन-विशिष्ट Vulkan त्वरण का भी समर्थन करते हैं ([OmniVoice](../../docs/engines/omnivoice-gguf.md#vulkan-acceleration), [CosyVoice](../../docs/engines/cosyvoice-gguf.md))। OmniVoice GGUF, Windows और Linux पर GPU और मॉडल का आकार अपने आप चुनता है। छिपी हुई जाँच अटकने पर Vulkan पहचान नेटिव सारांश के साथ दोबारा प्रयास करती है; Windows और Linux डेस्कटॉप बिल्ड Vulkan मॉड्यूल के बिना चुपचाप जारी होने के बजाय विफल हो जाते हैं।

<a id="get-started"></a>

## शुरू करें

उपरोक्त विकल्पों का उपयोग करके इंस्टॉल करें. फिर **आवाज क्लोनिंग** खोलें, एक आवाज चुनें या एक साफ संदर्भ रिकॉर्डिंग जोड़ें, अपना टेक्स्ट टाइप करें और जेनरेट करें। ऐप किसी भी मॉडल को डाउनलोड करने से पहले पूछता है।

<details>
<summary><strong>अधिक इंस्टॉल विकल्प</strong>: एक विशिष्ट संस्करण, वर्तमान मुख्य, अनइंस्टॉल, स्रोत से, एक कोडिंग एजेंट के साथ</summary>

```sh
curl -fsSL https://voicestudio.sh/install | sh -s -- --version X.Y.Z   # a specific release
curl -fsSL https://voicestudio.sh/install | sh -s -- --main            # build current main
curl -fsSL https://voicestudio.sh/install | sh -s -- --uninstall       # remove the app, keep your data
```

यदि `voicestudio.sh` पहुंच योग्य नहीं है, तो स्क्रिप्ट को सीधे रिपॉजिटरी से चलाएँ: `curl -fsSL https://raw.githubusercontent.com/debpalash/VoiceStudio/main/scripts/install.sh | sh`। पूर्वापेक्षाएँ और व्यवहार: [इंस्टॉलर गाइड](../../docs/install/script.md)।

**स्रोत से**

```bash
git clone https://github.com/debpalash/VoiceStudio.git
cd VoiceStudio
bun run dev
```

`bun run dev` जावास्क्रिप्ट निर्भरताएँ स्थापित करता है और, समर्थित स्थानीय बैकएंड का उपयोग करते समय, इलेक्ट्रॉन लॉन्च करने से पहले पायथन निर्भरताएँ स्थापित करता है। जब आपको केवल Python वातावरण का पुनर्निर्माण करने की आवश्यकता हो तो सीधे `bun run setup:api` चलाएँ।

[इलेक्ट्रॉन सेटअप](../../electron/README.md) देखें।

**एक कोडिंग एजेंट के साथ** (क्लाउड कोड, कोडेक्स, कर्सर,…), पेस्ट करें:

```text
Install the VoiceStudio app on this device and verify it works, following
https://github.com/debpalash/VoiceStudio/blob/main/docs/install/agent.md
```

0.5.3 या पुराने (टौरी ऐप) से अपग्रेड करना? [नया ऐप अलग से इंस्टॉल करें](../../docs/electron-migration.md)।

</details>
