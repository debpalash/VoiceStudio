## Plataformas

Elija su sistema, luego expanda un método de instalación.

Los motores GGUF nativos también admiten aceleración Vulkan específica de cada motor en GPU AMD, Intel y NVIDIA ([OmniVoice](../../docs/engines/omnivoice-gguf.md#vulkan-acceleration), [CosyVoice](../../docs/engines/cosyvoice-gguf.md)). OmniVoice GGUF selecciona automáticamente la GPU y el tamaño del modelo en Windows y Linux. Si una comprobación oculta se bloquea, la detección de Vulkan vuelve a intentarlo con un resumen nativo; las compilaciones de escritorio de Windows y Linux fallan en lugar de distribuirse silenciosamente sin su módulo Vulkan.

<a id="install-windows"></a>

<details>
<summary><img src="../../docs/assets/platforms/windows.svg" alt="" width="20" height="20" /> <strong>Windows</strong> · PowerShell · EXE</summary>

La [configuración experimental de Windows ROCm](../../docs/install/windows-rocm.md) admite determinadas GPU RDNA 2 RX 6000 con objetivos `gfx1030`, `gfx1031` o `gfx1032`; la RX 6500 XT (`gfx1034`) queda excluida. La compilación de CTranslate2 con versión fijada por separado incluye kernels nativos `gfx1031` para transcribir en la RX 6700 XT; la configuración comprueba su ejecución real en la GPU. Las pruebas de la RX 6700 XT también cubren la generación de voz nativa con Torch y PyTorch Whisper. En ROCm 10, faster-whisper usa un proceso de inferencia separado para seleccionar la CPU o recurrir a ella con seguridad. Otras tarjetas y cargas de trabajo conservan los límites de validación de la guía. Los perfiles de rendimiento validan los cambios de motor en un proceso secundario sin conexión antes de guardarlos, manteniendo la alternativa si falla un entorno instalado.

<blockquote>

**Estable · x64**<br />Windows 10/11 x64 · NVIDIA CUDA · AMD ROCm (opcional) · CPU.

```powershell

```

[Descargue el instalador de Windows](https://github.com/debpalash/VoiceStudio/releases/latest) · [Guía](../../docs/install/windows.md) · [AMD ROCm](../../docs/install/windows-rocm.md)

<a id="install-docker"></a>

<details>
<summary><img src="../../docs/assets/platforms/docker.svg" alt="" width="20" height="20" /> <strong>Docker</strong> · GHCR · Docker Hub</summary>

<blockquote>

Imágenes estables de contenedor · CPU · NVIDIA CUDA · AMD ROCm.

<a href="https://github.com/debpalash/VoiceStudio/pkgs/container/voicestudio"><img src="https://img.shields.io/badge/GHCR-27272a?style=flat-square&amp;logo=github&amp;logoColor=ffffff" alt="GHCR" height="20" /></a>

**Ejecutar localmente en la CPU (Bash)**

```sh
export OMNIVOICE_API_KEY="$(openssl rand -hex 32)"
docker run -d --name omnivoice \
  -p 127.0.0.1:3900:3900 \
  -e OMNIVOICE_API_KEY \
  -e OMNIVOICE_DATA_DIR=/app/omnivoice_data \
  -v omnivoice-data:/app/omnivoice_data \
  ghcr.io/debpalash/voicestudio:stable
printf 'API key: %s\n' "$OMNIVOICE_API_KEY"
```

Abra http://localhost:3900 y utilice la clave API impresa a continuación.

[Instrucciones para NVIDIA, AMD ROCm y Compose](../../docs/install/docker.md)

[Espejo de Docker Hub](https://hub.docker.com/r/palashdeb/omnivoice-studio): `palashdeb/omnivoice-studio:stable`

Los instaladores de escritorio y teléfono están en la [última versión](https://github.com/debpalash/VoiceStudio/releases/latest); Las imágenes de Docker provienen de GHCR. ¿Sin GPU? La aplicación es totalmente utilizable en la CPU, sólo que más lenta. Los motores nativos GGUF también pueden usar Vulkan en GPU AMD, Intel y NVIDIA; OmniVoice GGUF elige su GPU y tamaño de modelo automáticamente en Windows y Linux ([OmniVoice](../../docs/engines/omnivoice-gguf.md#vulkan-acceleration), [CosyVoice](../../docs/engines/cosyvoice-gguf.md)). Velocidad por motor y hardware: [rendimiento](../../docs/performance.md).


<a id="get-started"></a>

## Primeros pasos

Instale usando las opciones anteriores. Luego abra **Clonación de voz**, elija una voz o agregue una grabación de referencia limpia, escriba su texto y genere. La aplicación pregunta antes de descargar cualquier modelo.

<details>
<summary><strong>Más opciones de instalación</strong>: una versión específica, principal actual, desinstalar, desde la fuente, con un agente de codificación</summary>

```sh
curl -fsSL https://voicestudio.sh/install | sh -s -- --version X.Y.Z   # a specific release
curl -fsSL https://voicestudio.sh/install | sh -s -- --main            # build current main
curl -fsSL https://voicestudio.sh/install | sh -s -- --uninstall       # remove the app, keep your data
```

Si no se puede acceder a `voicestudio.sh`, ejecute el script directamente desde el repositorio: `curl -fsSL https://raw.githubusercontent.com/debpalash/VoiceStudio/main/scripts/install.sh | sh`. Requisitos previos y comportamiento: [guía del instalador](../../docs/install/script.md).

**De la fuente**

```bash
git clone https://github.com/debpalash/VoiceStudio.git
cd VoiceStudio
bun run dev
```

`bun run dev` instala las dependencias de JavaScript y, cuando se utiliza un backend local compatible, las dependencias de Python antes de iniciar Electron. Ejecute `bun run setup:api` directamente cuando solo necesite reconstruir el entorno Python.

Consulta [Configuración de Electron](../../electron/README.md).

**Con un agente codificador** (Claude Code, Codex, Cursor,…), pegue:

```text
Install the VoiceStudio app on this device and verify it works, following
https://github.com/debpalash/VoiceStudio/blob/main/docs/install/agent.md
```

¿Actualizando desde 0.5.3 o anterior (la aplicación Tauri)? [Instale la nueva aplicación por separado](../../docs/electron-migration.md).

</details>
