## 対応プラットフォーム

OS を選び、使いたいインストール方法を展開してください。

ネイティブ GGUF エンジンは、AMD、Intel、NVIDIA の GPU でエンジン固有の Vulkan アクセラレーションも利用できます（[OmniVoice](../../docs/engines/omnivoice-gguf.md#vulkan-acceleration), [CosyVoice](../../docs/engines/cosyvoice-gguf.md)）。OmniVoice GGUF は Windows と Linux で GPU とモデルサイズを自動選択します。非表示の検査が停止した場合、Vulkan 検出はネイティブの概要を使って再試行します。Windows と Linux のデスクトップビルドは、Vulkan モジュールを欠いたまま公開されることを防ぐため、モジュールがないと失敗します。

<a id="install-windows"></a>

<details>
<summary><img src="../../docs/assets/platforms/windows.svg" alt="" width="20" height="20" /> <strong>Windows</strong> · PowerShell · EXE</summary>

実験的な [Windows ROCm セットアップ](../../docs/install/windows-rocm.md)は、ターゲットが `gfx1030`、`gfx1031`、`gfx1032` の一部の RDNA 2 RX 6000 GPU に対応しています。RX 6500 XT（`gfx1034`）は対象外です。個別にバージョンを固定した CTranslate2 ビルドには、RX 6700 XT での文字起こし用のネイティブ `gfx1031` カーネルが含まれ、セットアップ時に GPU カーネルの実際の実行を確認します。RX 6700 XT のテストには、ネイティブ Torch 音声生成と PyTorch Whisper も含まれます。ROCm 10 の faster-whisper は推論を別プロセスで行い、安全な CPU 選択と CPU へのフォールバックを維持します。他のカードや処理には、ガイドに記載された検証範囲の制限が適用されます。パフォーマンスプリセットは、変更されたエンジン選択を保存する前にオフラインの子プロセスで実行環境の準備状況を検証し、インストール済み環境で障害が起きた場合もフォールバックを維持します。

<blockquote>

**安定版 · x64**<br />Windows 10/11 x64 · NVIDIA CUDA · AMD ROCm（任意で有効化）· CPU。

```powershell
irm https://voicestudio.sh/install.ps1 | iex
```

[Windows インストーラーをダウンロード](https://github.com/debpalash/VoiceStudio/releases/latest) · [ガイド](../../docs/install/windows.md) · [AMD ROCm](../../docs/install/windows-rocm.md)

<details>
<summary>Windows on ARM · 実験的</summary>

UI はネイティブで動作し、x64 Python バックエンドは CPU 上のエミュレーションで実行されます。

[ダウンロード](https://github.com/debpalash/VoiceStudio/releases/latest) · [ガイド](../../docs/install/windows.md)

</details>

</blockquote>

```sh
export OMNIVOICE_API_KEY="$(openssl rand -hex 32)"
docker run -d --name omnivoice \
  -p 127.0.0.1:3900:3900 \
  -e OMNIVOICE_API_KEY \
  -e OMNIVOICE_DATA_DIR=/app/omnivoice_data \
  -v omnivoice-data:/app/omnivoice_data \
  ghcr.io/debpalash/voicestudio:stable
printf 'API key: %s\n' "$OMNIVOICE_API_KEY"
```

http://localhost:3900 を開き、下に表示される API キーを使ってください。

[NVIDIA、AMD ROCm、Compose の手順](../../docs/install/docker.md)

[Docker Hub ミラー](https://hub.docker.com/r/palashdeb/omnivoice-studio): `palashdeb/omnivoice-studio:stable`

<a id="get-started"></a>

## はじめに

上記の方法でインストールしたら、**音声クローン** を開き、声を選ぶか明瞭な参照録音を追加し、テキストを入力して生成してください。モデルをダウンロードする前に確認が表示されます。

<details>
<summary><strong>その他のインストール方法</strong>：特定のバージョン、最新の main、アンインストール、ソースから、コーディングエージェントで</summary>

```sh
curl -fsSL https://voicestudio.sh/install | sh -s -- --version X.Y.Z   # 特定のリリース
curl -fsSL https://voicestudio.sh/install | sh -s -- --main            # 最新の main をビルド
curl -fsSL https://voicestudio.sh/install | sh -s -- --uninstall       # データを残してアプリを削除
```

`voicestudio.sh` にアクセスできない場合は、リポジトリから直接スクリプトを実行できます：
`curl -fsSL https://raw.githubusercontent.com/debpalash/VoiceStudio/main/scripts/install.sh | sh`。
前提条件と動作：[インストーラーガイド](../../docs/install/script.md)。

**ソースから**

```bash
git clone https://github.com/debpalash/VoiceStudio.git
cd VoiceStudio
bun run dev
```

`bun run dev` は JavaScript の依存関係をインストールし、対応するローカルバックエンドを使用する場合は Python の依存関係もインストールしてから Electron を起動します。Python 環境だけを再構築する場合は、`bun run setup:api` を直接実行してください。

[Electron のセットアップ](../../electron/README.md)を参照してください。

**コーディングエージェントで**（Claude Code、Codex、Cursor など）、次の内容を貼り付けます：

```text
Install the VoiceStudio app on this device and verify it works, following
https://github.com/debpalash/VoiceStudio/blob/main/docs/install/agent.md
```

0.5.3 以前（Tauri 版アプリ）からアップグレードする場合は、[新しいアプリを別途インストール](../../docs/electron-migration.md)してください。

</details>
