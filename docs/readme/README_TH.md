## แพลตฟอร์ม

เลือกระบบของคุณ จากนั้นขยายวิธีการติดตั้ง

เอนจิน GGUF แบบเนทีฟยังรองรับการเร่งความเร็ว Vulkan เฉพาะเอนจินบน GPU ของ AMD, Intel และ NVIDIA ([OmniVoice](../../docs/engines/omnivoice-gguf.md#vulkan-acceleration), [CosyVoice](../../docs/engines/cosyvoice-gguf.md)) OmniVoice GGUF เลือก GPU และขนาดโมเดลโดยอัตโนมัติบน Windows และ Linux หากการตรวจสอบที่ซ่อนอยู่ค้าง การตรวจหา Vulkan จะลองใหม่ด้วยข้อมูลสรุปแบบเนทีฟ ส่วนบิลด์เดสก์ท็อป Windows และ Linux จะล้มเหลวแทนการเผยแพร่โดยไม่มีโมดูล Vulkan อย่างเงียบ ๆ

[การตั้งค่า Windows ROCm แบบทดลอง](../../docs/install/windows-rocm.md) รองรับ GPU RDNA 2 RX 6000 บางรุ่นที่มีเป้าหมายเป็น `gfx1030`, `gfx1031` หรือ `gfx1032` โดยไม่รวม RX 6500 XT (`gfx1034`) บิลด์ CTranslate2 ที่ตรึงเวอร์ชันแยกต่างหากมีเคอร์เนล `gfx1031` แบบเนทีฟสำหรับการถอดเสียงบน RX 6700 XT โดยขั้นตอนตั้งค่าจะตรวจสอบการทำงานจริงของเคอร์เนลบน GPU การทดสอบ RX 6700 XT ยังครอบคลุมการสร้างเสียงพูดด้วย Torch แบบเนทีฟและ PyTorch Whisper ด้วย faster-whisper บน ROCm 10 ใช้กระบวนการอนุมานแยกต่างหากเพื่อให้เลือก CPU และสลับกลับไปใช้ CPU ได้อย่างปลอดภัย การ์ดและงานประเภทอื่นยังอยู่ภายใต้ข้อจำกัดการตรวจสอบในคู่มือ ค่าประสิทธิภาพที่ตั้งไว้ล่วงหน้าจะตรวจสอบความพร้อมของรันไทม์สำหรับเอนจินที่เปลี่ยนในกระบวนการลูกแบบออฟไลน์ก่อนบันทึก และคงทางเลือกสำรองไว้หากรันไทม์ที่ติดตั้งล้มเหลว

## เริ่มต้นใช้งาน

Install using the options above. จากนั้นเปิด **การโคลนเสียง** เลือกเสียงหรือเพิ่มการบันทึกอ้างอิงที่ชัดเจน พิมพ์ข้อความของคุณและสร้าง แอพจะถามก่อนที่จะดาวน์โหลดรุ่นใด ๆ

<details>
<summary><strong>ตัวเลือกการติดตั้งเพิ่มเติม</strong>: เวอร์ชันเฉพาะ, หลักปัจจุบัน, ถอนการติดตั้ง, จากแหล่งที่มา, ด้วยเอเจนต์การเข้ารหัส</summary>

```sh
curl -fsSL https://voicestudio.sh/install | sh -s -- --version X.Y.Z   # a specific release
curl -fsSL https://voicestudio.sh/install | sh -s -- --main            # build current main
curl -fsSL https://voicestudio.sh/install | sh -s -- --uninstall       # remove the app, keep your data
```

หากไม่สามารถเข้าถึง `voicestudio.sh` ให้รันสคริปต์จากที่เก็บโดยตรง: `curl -fsSL https://raw.githubusercontent.com/debpalash/VoiceStudio/main/scripts/install.sh | sh` ข้อกำหนดเบื้องต้นและลักษณะการทำงาน: [คู่มือการติดตั้ง](../../docs/install/script.md)

**จากซอร์สโค้ด**

```bash
git clone https://github.com/debpalash/VoiceStudio.git
cd VoiceStudio
bun run dev
```

`bun run dev` จะติดตั้งการขึ้นต่อกันของ JavaScript และเมื่อใช้แบ็กเอนด์ในเครื่องที่รองรับ จะติดตั้งการขึ้นต่อกันของ Python ก่อนที่จะเรียกใช้ Electron เรียกใช้ `bun run setup:api` โดยตรงเมื่อคุณต้องการสร้างสภาพแวดล้อม Python ใหม่เท่านั้น

ดู [การตั้งค่า Electron](../../electron/README.md).

**ใช้เอเจนต์ช่วยเขียนโปรแกรม** (Claude Code, Codex, Cursor, …) โดยวางข้อความนี้:

```text
Install the VoiceStudio app on this device and verify it works, following
https://github.com/debpalash/VoiceStudio/blob/main/docs/install/agent.md
```

กำลังอัปเกรดจาก 0.5.3 หรือเก่ากว่า (แอป Tauri) [ติดตั้งแอปใหม่แยกต่างหาก](../../docs/electron-migration.md)

</details>
