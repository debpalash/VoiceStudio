## Platformlar

Sisteminizi seçin, ardından kurulum yöntemini genişletin.

Yerel GGUF motorları AMD, Intel ve NVIDIA GPU’larda motora özgü Vulkan hızlandırmasını da destekler ([OmniVoice](../../docs/engines/omnivoice-gguf.md#vulkan-acceleration), [CosyVoice](../../docs/engines/cosyvoice-gguf.md)). OmniVoice GGUF, Windows ve Linux üzerinde GPU’yu ve model boyutunu otomatik seçer. Gizli bir denetim takılırsa Vulkan algılama yerel bir özetle yeniden dener; Windows ve Linux masaüstü derlemeleri Vulkan modülü olmadan sessizce dağıtılmak yerine başarısız olur.

<a id="install-windows"></a>

<details>
<summary><img src="../../docs/assets/platforms/windows.svg" alt="" width="20" height="20" /> <strong>Windows</strong> · PowerShell · EXE</summary>

Deneysel [Windows ROCm kurulumu](../../docs/install/windows-rocm.md), `gfx1030`, `gfx1031` veya `gfx1032` hedefli belirli RDNA 2 RX 6000 GPU’ları destekler; RX 6500 XT (`gfx1034`) kapsam dışındadır. Sürümü ayrıca sabitlenen CTranslate2 derlemesi, RX 6700 XT üzerinde transkripsiyon için yerel `gfx1031` çekirdekleri içerir; kurulum GPU çekirdeklerinin gerçekten çalıştığını doğrular. RX 6700 XT testleri, yerel Torch konuşma üretimini ve PyTorch Whisper’ı da kapsar. ROCm 10 üzerinde faster-whisper, güvenli CPU seçimi ve CPU’ya geri dönüş için ayrı bir çıkarım süreci kullanır. Diğer kartlar ve iş yükleri kılavuzdaki doğrulama sınırlarına tabidir. Performans ön ayarları, değiştirilen motor seçimlerinin çalışma zamanı hazırlığını kaydetmeden önce çevrimdışı bir alt süreçte doğrular ve kurulu bir çalışma zamanı başarısız olursa geri dönüş seçeneğini korur.

<blockquote>

**Kararlı · x64**<br />Windows 10/11 x64 · NVIDIA CUDA · AMD ROCm (isteğe bağlı) · CPU.

```powershell
irm https://voicestudio.sh/install.ps1 | iex
```

[Windows yükleyicisini indirin](https://github.com/debpalash/VoiceStudio/releases/latest) · [Kılavuz](../../docs/install/windows.md) · [AMD ROCm](../../docs/install/windows-rocm.md)

[İndir](https://github.com/debpalash/VoiceStudio/releases/latest) · [Kılavuz](../../docs/install/windows.md)

<a id="install-docker"></a>

<details>
<summary><img src="../../docs/assets/platforms/docker.svg" alt="" width="20" height="20" /> <strong>Docker</strong> · GHCR · Docker Hub</summary>

<blockquote>

Kararlı konteyner imajları · CPU · NVIDIA CUDA · AMD ROCm.

<a href="https://github.com/debpalash/VoiceStudio/pkgs/container/voicestudio"><img src="https://img.shields.io/badge/GHCR-27272a?style=flat-square&amp;logo=github&amp;logoColor=ffffff" alt="GHCR" height="20" /></a>

**CPU üzerinde yerel olarak çalıştır (Bash)**

```sh
export OMNIVOICE_API_KEY="$(openssl rand -hex 32)"
docker run -d --name omnivoice \
  -p 127.0.0.1:3900:3900 \
  -e OMNIVOICE_API_KEY \
  -e OMNIVOICE_DATA_DIR=/app/omnivoice_data \
  -v omnivoice-data:/app/omnivoice_data \
  ghcr.io/debpalash/voicestudio:stable
printf 'API key: %s\n' "$OMNIVOICE_API_KEY"
```

http://localhost:3900'yu açın ve aşağıda yazılı olan API anahtarını kullanın.

[NVIDIA, AMD ROCm ve Compose talimatları](../../docs/install/docker.md)

[Docker Hub aynası](https://hub.docker.com/r/palashdeb/omnivoice-studio): `palashdeb/omnivoice-studio:stable`

## Başlarken

Yukarıdaki seçenekleri kullanarak kurulum yapın. Ardından **Ses klonlama**'yı açın, bir ses seçin veya temiz bir referans kaydı ekleyin, metninizi yazın ve oluşturun. Uygulama herhangi bir modeli indirmeden önce sorar.

<details>
<summary><strong>Daha fazla kurulum seçeneği</strong>: belirli bir sürüm, güncel main dalı, kaldırma, kaynak koddan veya bir kodlama ajanıyla kurulum</summary>

```sh
curl -fsSL https://voicestudio.sh/install | sh -s -- --version X.Y.Z   # a specific release
curl -fsSL https://voicestudio.sh/install | sh -s -- --main            # build current main
curl -fsSL https://voicestudio.sh/install | sh -s -- --uninstall       # remove the app, keep your data
```

`voicestudio.sh`'ya erişilemiyorsa betiği doğrudan depodan çalıştırın: `curl -fsSL https://raw.githubusercontent.com/debpalash/VoiceStudio/main/scripts/install.sh | sh`. Önkoşullar ve davranış: [kurulum kılavuzu](../../docs/install/script.md).

**Kaynaktan**

```bash
git clone https://github.com/debpalash/VoiceStudio.git
cd VoiceStudio
bun run dev
```

`bun run dev`, Electron'u başlatmadan önce JavaScript bağımlılıklarını ve desteklenen bir yerel arka uç kullanıldığında Python bağımlılıklarını yükler. Yalnızca Python ortamını yeniden oluşturmanız gerektiğinde `bun run setup:api`'yu doğrudan çalıştırın.

Bkz. [Electron kurulumu](../../electron/README.md).

**Kodlama aracısıyla** ( Claude Code, Codex, Cursor, …), şunu yapıştırın:

```text
Install the VoiceStudio app on this device and verify it works, following
https://github.com/debpalash/VoiceStudio/blob/main/docs/install/agent.md
```

0.5.3 veya daha eski bir sürümden (Tauri uygulaması) yükseltme mi yapıyorsunuz? [Yeni uygulamayı ayrı olarak yükleyin](../../docs/electron-migration.md).

</details>
