## Nền tảng

Chọn hệ thống của bạn, sau đó mở rộng phương pháp cài đặt.

Các bộ máy GGUF gốc cũng hỗ trợ tăng tốc Vulkan riêng cho từng bộ máy trên GPU AMD, Intel và NVIDIA ([OmniVoice](../../docs/engines/omnivoice-gguf.md#vulkan-acceleration), [CosyVoice](../../docs/engines/cosyvoice-gguf.md)). OmniVoice GGUF tự động chọn GPU và kích thước mô hình trên Windows và Linux. Nếu phép kiểm tra ẩn bị treo, quá trình phát hiện Vulkan thử lại bằng bản tóm tắt gốc; các bản dựng máy tính Windows và Linux sẽ thất bại thay vì âm thầm được phát hành mà thiếu mô-đun Vulkan.

<a id="install-windows"></a>

<details>
<summary><img src="../../docs/assets/platforms/windows.svg" alt="" width="20" height="20" /> <strong>Windows</strong> · PowerShell · EXE</summary>

[Thiết lập Windows ROCm](../../docs/install/windows-rocm.md) thử nghiệm hỗ trợ một số GPU RDNA 2 RX 6000 có đích `gfx1030`, `gfx1031` hoặc `gfx1032`; không bao gồm RX 6500 XT (`gfx1034`). Bản dựng CTranslate2 được ghim phiên bản riêng bao gồm nhân `gfx1031` gốc để chép lời trên RX 6700 XT; quá trình thiết lập kiểm tra việc thực thi nhân GPU thực tế. Các thử nghiệm RX 6700 XT cũng bao gồm tạo giọng nói Torch gốc và PyTorch Whisper. Trên ROCm 10, faster-whisper dùng tiến trình suy luận riêng để chọn CPU và chuyển về CPU an toàn. Các thẻ và khối lượng công việc khác vẫn tuân theo giới hạn kiểm chứng trong hướng dẫn. Cấu hình hiệu năng đặt sẵn xác minh trạng thái sẵn sàng của các bộ máy được thay đổi trong tiến trình con ngoại tuyến trước khi lưu, đồng thời giữ phương án dự phòng nếu môi trường thực thi đã cài đặt bị lỗi.

<blockquote>

**Ổn định · x64**<br />Windows 10/11 x64 · NVIDIA CUDA · AMD ROCm (tùy chọn) · CPU.


[Tải xuống trình cài đặt Windows](https://github.com/debpalash/VoiceStudio/releases/latest) · [Hướng dẫn](../../docs/install/windows.md) · [AMD ROCm](../../docs/install/windows-rocm.md)

**Chạy cục bộ trên CPU (Bash)**

```sh
export OMNIVOICE_API_KEY="$(openssl rand -hex 32)"
docker run -d --name omnivoice \
  -p 127.0.0.1:3900:3900 \
  -e OMNIVOICE_API_KEY \
  -e OMNIVOICE_DATA_DIR=/app/omnivoice_data \
  -v omnivoice-data:/app/omnivoice_data \
  ghcr.io/debpalash/voicestudio:stable
printf 'API key: %s\n' "$OMNIVOICE_API_KEY"
```

Mở http://localhost:3900 và sử dụng khóa API được in bên dưới.

## Bắt đầu

Cài đặt bằng các tùy chọn ở trên. Sau đó mở **Nhân bản giọng nói**, chọn giọng nói hoặc thêm bản ghi tham chiếu rõ ràng, nhập văn bản của bạn và tạo. Ứng dụng sẽ hỏi trước khi tải xuống bất kỳ mô hình nào.

<details>
<summary><strong>Tùy chọn cài đặt khác</strong>: phiên bản cụ thể, nhánh main hiện tại, gỡ cài đặt, cài từ mã nguồn hoặc dùng trợ lý lập trình</summary>

```sh
curl -fsSL https://voicestudio.sh/install | sh -s -- --version X.Y.Z   # a specific release
curl -fsSL https://voicestudio.sh/install | sh -s -- --main            # build current main
curl -fsSL https://voicestudio.sh/install | sh -s -- --uninstall       # remove the app, keep your data
```

Nếu không thể truy cập `voicestudio.sh`, hãy chạy tập lệnh trực tiếp từ kho lưu trữ: `curl -fsSL https://raw.githubusercontent.com/debpalash/VoiceStudio/main/scripts/install.sh | sh`. Điều kiện tiên quyết và hành vi: [hướng dẫn cài đặt](../../docs/install/script.md).

**Từ mã nguồn**

```bash
git clone https://github.com/debpalash/VoiceStudio.git
cd VoiceStudio
bun run dev
```

`bun run dev` cài đặt các gói phụ thuộc JavaScript và, khi dùng backend cục bộ được hỗ trợ, các gói phụ thuộc Python trước khi khởi chạy Electron. Nếu chỉ cần tạo lại môi trường Python, hãy chạy trực tiếp `bun run setup:api`.

Xem [Thiết lập Electron](../../electron/README.md).

**Với trợ lý lập trình** (Claude Code, Codex, Cursor, …), hãy dán:

```text
Install the VoiceStudio app on this device and verify it works, following
https://github.com/debpalash/VoiceStudio/blob/main/docs/install/agent.md
```

Nâng cấp từ phiên bản 0.5.3 trở xuống (ứng dụng Tauri)? [Cài riêng ứng dụng mới](../../docs/electron-migration.md).

</details>
