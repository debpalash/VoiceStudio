<a id="platforms"></a>

## Platformen

Kies uw systeem en breid vervolgens een installatiemethode uit.

Native GGUF-engines ondersteunen daarnaast enginespecifieke Vulkan-versnelling op GPU’s van AMD, Intel en NVIDIA ([OmniVoice](../../docs/engines/omnivoice-gguf.md#vulkan-acceleration), [CosyVoice](../../docs/engines/cosyvoice-gguf.md)). OmniVoice GGUF kiest op Windows en Linux automatisch de GPU en modelgrootte. Als een verborgen controle vastloopt, probeert Vulkan-detectie het opnieuw met een native samenvatting; desktopbuilds voor Windows en Linux mislukken als de Vulkan-module ontbreekt, zodat deze niet ongemerkt wordt weggelaten.

```sh
export OMNIVOICE_API_KEY="$(openssl rand -hex 32)"
docker run -d --name omnivoice \
  -p 127.0.0.1:3900:3900 \
  -e OMNIVOICE_API_KEY \
  -e OMNIVOICE_DATA_DIR=/app/omnivoice_data \
  -v omnivoice-data:/app/omnivoice_data \
  ghcr.io/debpalash/voicestudio:stable
printf 'API key: %s\n' "$OMNIVOICE_API_KEY"
```

Open http://localhost:3900 en gebruik de hieronder afgedrukte API-sleutel.

<a id="get-started"></a>

## Aan de slag

Installeer met behulp van de bovenstaande opties. Open vervolgens **Stemklonen**, kies een stem of voeg een schone referentie-opname toe, typ uw tekst en genereer. De app vraagt ​​dit voordat een model wordt gedownload.

<details>
<summary><strong>Meer installatieopties</strong>: een specifieke versie, huidige hoofdversie, verwijdering, van de bron, met een coderingsagent</summary>

```sh
curl -fsSL https://voicestudio.sh/install | sh -s -- --version X.Y.Z   # a specific release
curl -fsSL https://voicestudio.sh/install | sh -s -- --main            # build current main
curl -fsSL https://voicestudio.sh/install | sh -s -- --uninstall       # remove the app, keep your data
```

Als `voicestudio.sh` onbereikbaar is, voert u het script rechtstreeks vanuit de repository uit: `curl -fsSL https://raw.githubusercontent.com/debpalash/VoiceStudio/main/scripts/install.sh | sh`. Vereisten en gedrag: [installatiehandleiding](../../docs/install/script.md).

**Van bron**

```bash
git clone https://github.com/debpalash/VoiceStudio.git
cd VoiceStudio
bun run dev
```

`bun run dev` installeert de JavaScript-afhankelijkheden en, bij gebruik van een ondersteunde lokale backend, de Python-afhankelijkheden voordat Electron wordt gestart. Voer `bun run setup:api` rechtstreeks uit wanneer u alleen de Python-omgeving opnieuw hoeft op te bouwen.

Zie [Elektronen instellen](../../electron/README.md).

**Met een codeeragent** (Claude Code, Codex, Cursor, ...), plak:

```text
Install the VoiceStudio app on this device and verify it works, following
https://github.com/debpalash/VoiceStudio/blob/main/docs/install/agent.md
```

Upgraden vanaf 0.5.3 of ouder (de Tauri-app)? [Installeer de nieuwe app afzonderlijk](../../docs/electron-migration.md).
