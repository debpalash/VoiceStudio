## Платформи

Виберіть свою систему, а потім розгорніть спосіб встановлення.

Нативні рушії GGUF також підтримують власне прискорення Vulkan на GPU AMD, Intel і NVIDIA ([OmniVoice](../../docs/engines/omnivoice-gguf.md#vulkan-acceleration), [CosyVoice](../../docs/engines/cosyvoice-gguf.md)). OmniVoice GGUF автоматично вибирає GPU та розмір моделі у Windows і Linux. Якщо прихована перевірка зависає, виявлення Vulkan повторює спробу з нативним зведенням; настільні збірки для Windows і Linux завершуються помилкою замість непомітного випуску без модуля Vulkan.

<a id="install-windows"></a>

<details>
<summary><img src="../../docs/assets/platforms/windows.svg" alt="" width="20" height="20" /> <strong>Windows</strong> · PowerShell · EXE</summary>

Експериментальне [налаштування Windows ROCm](../../docs/install/windows-rocm.md) підтримує окремі GPU RDNA 2 RX 6000 з цільовими архітектурами `gfx1030`, `gfx1031` або `gfx1032`; RX 6500 XT (`gfx1034`) не підтримується. Окремо закріплена збірка CTranslate2 містить нативні ядра `gfx1031` для транскрипції на RX 6700 XT; налаштування перевіряє їхнє фактичне виконання на GPU. Тести RX 6700 XT також охоплюють нативне генерування мовлення Torch і PyTorch Whisper. У ROCm 10 faster-whisper використовує окремий процес інференсу для безпечного вибору CPU та повернення до нього в разі збою. Для інших карт і навантажень діють обмеження перевірки з посібника. Профілі продуктивності перевіряють змінений вибір рушіїв в автономному дочірньому процесі перед збереженням, залишаючи запасний варіант, якщо встановлене середовище виконання не працює.

<blockquote>

**Стабільна · x64**<br />Windows 10/11 x64 · NVIDIA CUDA · AMD ROCm (за бажанням) · ЦП.

```powershell
irm https://voicestudio.sh/install.ps1 | iex
```

[Завантажити програму встановлення Windows](https://github.com/debpalash/VoiceStudio/releases/latest) · [Посібник](../../docs/install/windows.md) · [AMD ROCm](../../docs/install/windows-rocm.md)

[Завантажити](https://github.com/debpalash/VoiceStudio/releases/latest) · [Посібник](../../docs/install/windows.md)

```sh
export OMNIVOICE_API_KEY="$(openssl rand -hex 32)"

printf 'API key: %s\n' "$OMNIVOICE_API_KEY"
```

## Початок роботи

Встановіть, використовуючи параметри вище. Потім відкрийте **Клонування голосу**, виберіть голос або додайте чистий контрольний запис, введіть текст і згенеруйте. Програма запитує, перш ніж завантажувати будь-яку модель.

<details>
<summary><strong>Більше варіантів встановлення</strong>: конкретна версія, поточна гілка main, видалення, запуск із вихідного коду або за допомогою помічника-програміста</summary>

```sh
curl -fsSL https://voicestudio.sh/install | sh -s -- --version X.Y.Z   # a specific release
curl -fsSL https://voicestudio.sh/install | sh -s -- --main            # build current main
curl -fsSL https://voicestudio.sh/install | sh -s -- --uninstall       # remove the app, keep your data
```

Якщо `voicestudio.sh` недоступний, запустіть сценарій прямо зі сховища: `curl -fsSL https://raw.githubusercontent.com/debpalash/VoiceStudio/main/scripts/install.sh | sh`. Передумови та поведінка: [посібник інсталятора](../../docs/install/script.md).

**З джерела**

```bash
git clone https://github.com/debpalash/VoiceStudio.git
cd VoiceStudio
bun run dev
```

`bun run dev` встановлює залежності JavaScript і, якщо використовується підтримувана локальна серверна частина, залежності Python перед запуском Electron. Запустіть `bun run setup:api` безпосередньо, коли вам потрібно лише перебудувати середовище Python.

Див. [Налаштування Electron](../../electron/README.md).

**З помічником-програмістом** (Claude Code, Codex, Cursor, …) вставте:

```text
Install the VoiceStudio app on this device and verify it works, following
https://github.com/debpalash/VoiceStudio/blob/main/docs/install/agent.md
```

Оновлення з 0.5.3 або старішої версії (програма Tauri)? [Установіть нову програму окремо](../../docs/electron-migration.md).

</details>
